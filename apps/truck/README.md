# 潮見港コンテナ便

スマホで遊ぶ、コンテナ輸送の大型トラックのゲームです。架空の港町「潮見」が舞台です。

- ハンドルは、スマホを左右に傾けて切ります。スマホを傾けても、景色は水平のままです。
- 左下がブレーキ、右下がアクセルです。上の方を押すほど強く効きます。
- 積み込み場の停止枠には、前進で入って止めます。

## いまできること（土台）

- **トレーラーの動き**：トラクターと 40ft のシャーシを連結しています。
  - トレーラーは連結点に引かれて、内側を通ります。後退もできます。
  - 折れすぎると、ジャックナイフになって止まります。
  - 積んだ荷が重いほど、加速が鈍く、止まるまでの距離が長くなります。
- **傾きのハンドル**：
  - 横向きの左右どちら向きで持っても、同じ向きに効きます。
  - 「まっすぐ」はいつでも合わせ直せます。効きの強さは 3 段階です。
- **練習場**：
  - コーンのスラロームと、コンテナを高く積んだ通路があります。
  - 通路の先の門型クレーンの下に、停止枠があります。止めると、前後・左右・向きのずれを表示します。
  - コーンやコンテナの山にぶつかると止まり、ぶつかった回数を数えます。
- **クレーンでの積み込み**：
  - 停止枠で合格すると、視点が門型クレーンの運転室へ 1.5 秒かけて移り、操作もクレーン用に替わります。
  - スマホを左右に傾けると吊り具が左右へ、奥へ倒すと前へ動きます。急に動かすと、吊ったコンテナが揺れます。
  - 右のレバーで上げ下げし、↺ ↻ で吊り具の向きを回します。
  - シャーシの真上（前後・左右 ±15 cm、向き ±2°）で揺れが収まっていれば着地し、「ロック」で固定します。ずれていると荷台の端に乗ってしまいます。強く下ろすと「ぶつけた」と数えます。
  - ロックすると吊り具が上がり、運転の視点に戻ります。「発進してよい」の合図で走り出せます。
- **画質**：60 FPS を保つように自動で調整します。

## ひかり野線（train-sim）とつなぐ

トラックで運んだ 12ft コンテナを、ひかり野線の貨物列車が運びます。帰りの列車が持ち帰ったコンテナは、トラックの依頼になります。

1. **駅へ**：潮見精機で積み、潮見貨物駅へ運ぶ。
2. **貨物列車**：ひかり野線で、潮見台から山ノ口まで運ぶ。
3. **駅から**：帰りの列車が持ち帰った分を、トラックで町の届け先へ運ぶ。

つなぎ方は次のとおりです。

- はじめの画面の「ひかり野線とつなぐ」で連携コード（8 文字）を作り、ひかり野線のはじめの画面に入れます。
- 記録は、この Worker の `/api/*` と D1 に置きます（`src/worker/link.ts`）。
- D1 がまだないときや、つないでいないときは、端末の中だけの仮のコンテナで遊べます。

確かめる用の URL もあります。`?auto&job=toStation&autopilot=8` で、駅へ運ぶ依頼を自動で走らせます。

パソコンではキーボードでも動かせます。

| キー | 操作 |
|---|---|
| ← → | ハンドル |
| ↑ | アクセル |
| ↓ | ブレーキ |
| R | 前進と後退の切り替え |
| C | 視点の切り替え |
| Space | まっすぐを合わせ直す |
| クレーン：矢印 | 吊り具を前後左右へ |
| クレーン：W / S | 上げる / 下げる |
| クレーン：Z / X | 吊り具を回す |
| クレーン：L | ロック |

傾きのセンサーは https のページでしか使えません。スマホでは、公開した URL で遊んでください。

## Discord への通知

GitHub の CI（型の検査・テスト・ビルド）が終わるたびに、結果を Discord に 1 通送ります（`.github/notify-discord.sh`）。

1. Discord のチャンネルの設定 → 連携サービス → ウェブフック で、Webhook の URL を作る。
2. GitHub のこのリポジトリの Settings → Secrets and variables → Actions → New repository secret で、名前 `DISCORD_WEBHOOK_URL`、値にその URL を入れる。
3. 次の push から届きます。シークレットがない間は、知らせずに飛ばします（CI は失敗しません）。
