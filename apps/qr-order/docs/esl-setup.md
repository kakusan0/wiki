# 電子棚札（SoluM ST-GR29000）の設置

QR オーダーは、商品ごとに電子棚札用の画像（296×128、白・黒・赤）を作ります。棚札には、**商品の QR コード（読み取るとカートに入る）・商品名・価格（税込）** が表示されます。棚札は、オープンソースの **OpenEPaperLink** で動かします（SoluM 純正の管理サービスは使いません）。

```
QR オーダー（/esl/<商品ID>.jpg） ← 定期的に取りに来る ← 基地局（店の Wi-Fi） → 無線で表示 → 棚札
```

## 1. そろえるもの

| もの | 内容 |
| --- | --- |
| 棚札 | SoluM ST-GR29000（2.9 インチ、296×128、白・黒・赤、CR2450 ×2）。NFC 付きの ST-GR2900N、低温用の ST-GR2900L もある |
| 書き換え用の道具 | 棚札を OpenEPaperLink 用に書き換える道具（AP-Flasher ボード、または ATC1441 の ZBS_Flasher） |
| 基地局（AP） | OpenEPaperLink の基地局。店の Wi-Fi につなぎ、棚札と無線でやり取りする |

どの基地局・道具を選ぶかは、[OpenEPaperLink の Wiki](https://github.com/OpenEPaperLink/OpenEPaperLink/wiki) の最新の案内に従ってください。Wiki には、UC8151 という表示部品の棚札で、Nano AP と最新のファームウェアの組み合わせだと縦線が出ることがある、との注意があります（[ST-GR29000 のページ](https://github.com/OpenEPaperLink/OpenEPaperLink/wiki/2.9%E2%80%B3-ST%E2%80%90GR29000)）。

## 2. 手順

1. **棚札を書き換える**：Wiki の手順で、棚札を 1 枚ずつ OpenEPaperLink のファームウェアに書き換えます。書き換えに失敗すると、棚札が使えなくなることがあります。
2. **基地局を設置する**：店の Wi-Fi につなぎ、基地局の管理画面（ブラウザで開く）を表示します。電源を入れた棚札が、基地局の一覧に出てきます。
3. **QR オーダーの設定を確認する**：管理画面の「店舗 QR」で、**QR コードの更新を「なし」** にします。更新が有効だと、棚札の QR からは注文できません（期限切れの案内が出ます）。
4. **画像 URL を設定する**：管理画面の「店舗 QR」→「電子棚札（ST-GR29000）」に、商品ごとの表示のプレビューと画像 URL（`https://…/esl/<商品ID>.jpg`）が並びます。基地局の管理画面で棚札を選び、内容（content）に **「7 - Image URL」** を選んで、その商品の画像 URL を貼り付けます。取りに来る間隔は 15〜60 分がおすすめです（短いほど早く変わり、電池は早く減ります）。
5. **棚に付ける**：表示を確かめ、スマートフォンのカメラで QR を読み取って、その商品がカートに入ることを確認します。

## 3. 表示の決まり

- 左に商品の QR コード、右に商品名（最大 3 行。入らない分は「…」）と価格（税込、赤）。軽減税率の商品は「（税込・軽減税率）」、年齢確認が必要な商品は「※年齢確認」（赤）を添えます。
- 管理画面で商品を **無効** にすると、QR の代わりに「販売停止」と表示します。
- 商品名・価格・販売状態を変えると、次に基地局が取りに来たときに表示が変わります。変わっていなければ同じ画像（同じ ETag）を返します。
- QR コードには短いアドレス（`/p/<商品ID>`）を入れています。読み取ると、その商品をカートに入れるお客様画面に移ります。
- QR コードは約 2.5 cm 角です。読み取るときは、カメラを 10 cm ほどまで近づけてください。
- 価格は「180円」の形で表示します（このフォントでは「¥」が正しく表示されないため）。

## 4. 技術メモ

- 画像：296×128、ベースライン JPEG（4:4:4、品質 100）。色は白 (255,255,255)・黒 (0,0,0)・赤 (255,0,0) だけ。OpenEPaperLink の画像の決まり（[Image specifications](https://github.com/OpenEPaperLink/OpenEPaperLink/wiki/Image-specifications)）に合わせています。
- 文字：東雲ビットマップフォント 16 ドット（パブリックドメイン）。`src/vendor/shinonome16.bin` は、JF ドット東雲ゴシック 16（同じくパブリックドメイン）から作りました。
- JPEG の作成：jpeg-js 0.4.4（BSD-3-Clause）の encoder を `src/vendor/jpeg-encoder.js` に取り込み、Cloudflare Workers で動くよう出力を Uint8Array に固定しています。
- 実装：`src/esl.ts`（画像を描く）、`src/index.ts` の `/esl/:file` と `/p/:productId`。
