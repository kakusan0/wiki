# 潮見とひかり野線

架空の港町「潮見」と、潮見台から山ノ口まで走る「ひかり野線」の 1 つのゲームです。電車とトラックを運転します。名前の会社・町・路線は、すべて架空です。

はじめの画面で乗り物を選びます。URL で選ぶこともできます。

- `?mode=train`：電車を運転（もとの「ひかり野線 運転士」）
- `?mode=truck`：トラックの仕事（もとの「潮見港コンテナ便」）

前の公開先の `/train-sim/` と `/truck/` を開くと、ここへ移ります。

## いまの段階

2 つのゲームを、次の順に 1 つの世界にしていきます。

1. 1 つの作品にする（済み）。
2. 港町を、ひかり野線の世界の中に置く。トラックから、走る電車が見えるようにする（済み・いまここ）。
3. 潮見貨物駅を本線につなぎ、トラックと機関車を乗り換えられるようにする。
4. 山ノ口まで道路を通す。

## フォルダー

作りの全体は [設計書](docs/design.md) にあります。

| 場所 | 中身 |
|---|---|
| `src/main.ts` | 入口。選んだ乗り物の画面（`index.html` の template）を出して、プログラムを読み込む |
| `src/train/` | 電車：運転・時刻表・信号と連動・ほかの列車・線路と地形と町 |
| `src/truck/` | トラック：連結車の動き・傾きのハンドル・クレーン・港町の道路 |
| `src/worker/` | 荷物の記録置き場（`/api/*` と D1） |
| `tests/train/`・`tests/truck/` | 単体テスト |

## 電車の操作

Z 加速 / X ブレーキ / N 惰行 / Space 非常 / O ドア / K 喚呼 / A 放送 / H 警笛 / C 視点 / W ワイパー / M 消音

スマホは右のレバーを上下にすべらせます。

## トラックの操作

- ハンドルは、スマホを左右に傾けて切ります。スマホを傾けても、景色は水平のままです。
- 左下がブレーキ、右下がアクセルです。上の方を押すほど強く効きます。
- 積み込み場の停止枠には、前進で入って止めます。止めると、視点が門型クレーンの運転室へ移ります。

パソコンではキーボードでも動かせます。

| キー | 操作 |
|---|---|
| ← → | ハンドル |
| ↑ | アクセル |
| ↓ | ブレーキ |
| R | 前進と後退の切り替え |
| C | 視点の切り替え |
| Space | まっすぐを合わせ直す |
| クレーン：矢印 | 吊り具を前後左右へ |
| クレーン：W / S | 上げる / 下げる |
| クレーン：Z / X | 吊り具を回す |
| クレーン：L | ロック |

傾きのセンサーは https のページでしか使えません。スマホでは、公開した URL で遊んでください。

## 荷物のつながり

トラックで潮見貨物駅に運んだ 12ft コンテナを、貨物列車が山ノ口へ運びます。帰りの列車が持ち帰ったコンテナは、トラックの依頼になります。

- いまは、トラックの画面で作った連携コード（8 文字）を、電車の画面に入れてつなぎます。記録は `/api/*` と D1 に置きます。
- 3 の段階で、端末の中の記録だけで動くようにします（連携コードは要らなくなります）。

確かめる用の URL もあります。

- `?mode=truck&auto&job=toStation&autopilot=8`：トラックが、駅へ運ぶ依頼を自動で走ります。
- `?mode=train&route=freight&auto&autodrive=8`：貨物列車を自動運転にして、速く進めます。

## 開発

```bash
npm run dev -w apps/shiomi
```

```bash
npm test -w apps/shiomi
```
