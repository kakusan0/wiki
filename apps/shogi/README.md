# まちかど将棋

ブラウザで遊べる将棋。スマホにも対応しています。

## 遊び方（モード）
- **コンピューター対戦**：強さは入門・初級・中級・上級。先手・後手・振り駒を選べます。駒落ち（香・角・飛車・二枚・四枚・六枚）もあります。待った・ヒントが使えます。
- **二人で対戦**
  - この端末で交代に指す。手番の人が手前になるよう盤を回すこともできます。
  - オンライン：合言葉で部屋を作って相手を招待します。持ち時間は「秒読み 30 秒」「10 分＋秒読み 30 秒」「切れ負け 5 分」から選べます。通信が切れても戻れます。
- **詰将棋**：1 手・3 手・5 手詰め（独自に作り、テストで詰みを確かめた問題）。
- **駒の動かし方**：駒を選ぶと動ける場所が光ります。
- **小さい盤**：5五将棋（5×5）と、本作独自のミニ将棋（3×4）。

ルール：二歩・打ち歩詰め・行き所のない駒は指せません。千日手は引き分け（連続王手の千日手は王手をかけた側の負け）。入玉宣言は 24 点法です。

## 開発
```bash
npm ci
npm run dev        # 画面（オンライン対戦はつながらない）
npx wrangler dev   # サーバーごと（先に npm run build）
npm test           # ルール・コンピューター・詰将棋・オンラインの部屋の単体テスト
npm run test:online
npm run e2e
```

## 公開
Cloudflare Workers（静的ファイル＋Durable Objects）。main に push すると Workers Builds で自動で公開されます。
