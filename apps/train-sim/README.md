# ひかり野線 運転士

ブラウザで遊ぶ電車の運転シミュレーター（three.js）。架空の路線「ひかり野線」を、海辺の潮見台から山あいの山ノ口まで 4 駅 5.8 km 運転します。

- 時刻表・ドアの開け閉め・発車メロディ・出発信号・ATS・制限速度・停止位置・喚呼・車内放送・警笛・踏切・すれ違う列車
- カーブと勾配のある複線、海岸・町・田んぼ・川のトラス橋・トンネル・山の森
- 画面の後処理：物の陰の暗がり（GTAO）、光のにじみ、色の調子、速さのぼかし、遠くまでの細かい影（CSM）

## 操作
Z 加速 / X ブレーキ / N 惰行 / Space 非常 / O ドア / K 喚呼 / A 放送 / H 警笛 / C 視点 / W ワイパー / M 消音

## 貨物列車（トラックのゲームとつながる）

路線の選択にある「貨物列車」は、ひかり野線の線路を走ります。潮見台（となりの潮見貨物駅）を出て、途中の駅は通過し、山ノ口に止まります。

- **トラックのゲームとつなぐ**：はじめの画面の「トラックのゲームとつなぐ」に、トラックのゲームで作った連携コードを入れます。
- **積むコンテナ**：トラックで潮見貨物駅に運んだ 12ft コンテナを、コンテナ貨車に積んで走ります。
- **着いたあと**：運んだ分は山ノ口に届きます。帰りの列車は町あてのコンテナを駅に持ち帰り、それがトラックの依頼になります。
- **つなぎ先**：トラックのゲームの公開先です。ビルドのときの `VITE_LINK_API` で決め、確かめるときは `?api=` で差し替えられます。
- **つないでいないとき**：仮のコンテナで走ります。

確かめる用：`?route=freight&auto&autodrive=8` で、貨物列車を自動運転にして速く進めます。
