# 電光花札 こいこい

光の空間に浮かぶ立体の花札で遊ぶ、こいこいのゲームです。ブラウザで遊べ、スマホにも対応しています。

## 遊び方
- **コンピューター対戦**：強さは「やさしい・ふつう・つよい」。3・6・12 か月から選べます。途中でやめても続きから遊べます。
- **オンライン対戦**：合言葉で部屋を作って友だちを招待します。1 手の持ち時間は 30 秒（過ぎると自動で指します）。通信が切れても戻れます。スタンプを送れます。
- 役の決まり（花見で一杯・月見で一杯、菊に盃をカスに数える、7 点以上は倍、こいこい返しで倍）は設定で変えられます。

## 表示と演出
- WebGL の 3D：厚みのある札が空中に浮かび、手札から弧を描いて飛び、山の札は目の前でめくれます。役ができると札が空中に並んで光ります。
- 応援ゲージ（得点には関係しない演出）、最後の月の「最終決戦」、こいこいの衝撃、効果音（消せます）。
- WebGL が使えない端末や軽くしたいときは 2D 表示に切り替えられます。
- 札の絵柄・画面・演出は、このゲームのために作った独自のものです。

## 開発
```bash
npm ci
npm run dev        # 画面（オンライン対戦はつながらない）
npx wrangler dev   # サーバーごと（先に npm run build）
npm test           # ルール・役・コンピューター・オンラインの部屋の単体テスト
npm run test:online
npm run e2e
```

## 公開
Cloudflare Workers（静的ファイル＋Durable Objects）。main に push すると Workers Builds で自動で公開されます。
