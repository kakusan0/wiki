# 星海の宝船 設計書

ブラウザで遊ぶ 3D のメダルプッシャーです。この文書は、作りを直す人・足す人のための設計のまとめです。遊び方は [README](../README.md) にあります。

## 1. 目的と範囲

- PC とスマホのブラウザで、1 人でメダルプッシャーを遊べるようにする。
- 台：上段・下段の 2 つの台とプッシャー、奥の 3 つのチャッカー、液晶のスロット、ボール、星図ルーレット、帆ゲージとジャックポット。
- 毎日 1 回のメダルの配給（7 日で一回り）。
- **メダルはゲームの中だけのもの**。買うこと、お金や景品に換えることはできない（課金・換金の仕組みは作らない）。
- 範囲の外：サーバーへの記録、ランキング、ほかの人との対戦。

## 2. 全体の作り

```
ブラウザだけで動く（サーバーの処理はない）
  ├─ 台のルール（src/game/）… 画面に依存しない計算。乱数は外から渡す
  ├─ 3D の台（src/ui/scene.ts）… three.js
  └─ localStorage：台の上のメダルまで含めた保存・設定・毎日の配給
```

- 公開は Cloudflare Workers（静的ファイルだけ）。作品 wiki の入口の Worker が `/medal-pusher/*` をこのアプリへ渡す。

## 3. ファイルと役割

| 場所 | 役割 |
|---|---|
| `src/game/sim.ts` | メダルの動き：上から見た 2 次元＋落ちる高さ。2 つの台・前後に動くプッシャー・壁・押し合い・落下 |
| `src/game/game.ts` | 台のルール：投入・チャッカー・スロット・ボール・ルーレット・帆ゲージ・ジャックポット・メダルの出入り・保存の形 |
| `src/game/daily.ts` | 毎日のメダル（続けて来るほど多い） |
| `src/ui/scene.ts` | 3D の台（メダル・プッシャー・液晶・ルーレット・チャッカー・光の演出） |
| `src/ui/screens.ts` | 液晶（スロット・お知らせ）とルーレットの盤の絵（Canvas） |
| `src/ui/textures.ts` | メダルの面・床・星空の絵（独自の図案を Canvas で描く） |
| `src/ui/sound.ts` | 効果音（Web Audio で作る短い音） |
| `src/main.ts` | 画面：タイトル・操作・出来事の表示・毎日の配給・記録と設定・ジャックポット・毎コマの進行 |

## 4. データ

### 4.1 台の大きさ（`sim.ts`）
| 名前 | 値 | 意味 |
|---|---|---|
| `R` | 0.22 | メダルの半径 |
| `BALL_R` | 0.34 | ボールの半径 |
| `HALF_W` | 2.6 | 台の幅の半分 |
| `UPPER_Y`・`LOWER_Y` | 1.2・0 | 上段・下段の高さ |
| `U_EDGE` | -1.4 | 上段の手前の縁（ここから下段へ落ちる） |
| `L_EDGE` | 2.6 | 下段の手前の縁（ここから落ちると払い出し） |
| `SIDE_OPEN_Z` | 1.75 | 下段はここより手前で横が開いている（横に落ちると戻らない） |
| `STROKE_T` | 3.2 秒 | プッシャーの往復 |

### 4.2 台のルールの値（`game.ts`）
| 名前 | 値 | 意味 |
|---|---|---|
| `CHUCKERS` | -1.7・0・1.7 | チャッカーの横の位置（入る幅は中心から 0.3） |
| `STOCK_MAX` | 4 | スロットの保留 |
| `INSERT_INTERVAL` | 0.18 秒 | 連続投入の間隔 |
| `SAIL_MAX` | 7 | 帆が 7 つで満帆（ジャックポット） |
| `JP_BASE` | 500 | ジャックポットのはじめの額 |
| スロットの当たり | 1/14 | はずれでも 4 回に 1 回はリーチを見せる |
| ルーレット | 12 ポケット | 波 +10・星 +30・帆（ゲージ +1、+5）・宝（25% でジャックポット、ほかは +40） |

### 4.3 端末に覚えるもの（localStorage）
| キー | 中身 |
|---|---|
| `medal/save-v1` | 持ちメダル・ジャックポットの額・帆ゲージ・保留・ルーレット待ちのボール・記録・台の上のメダル（位置・段・ボールか） |
| `medal/settings-v1` | 音・振動・演出の強さ（派手・ふつう・控えめ） |
| `medal/daily-v1` | 毎日の配給（最後に受け取った日・続けた日数） |

保存は 2 秒ごと・ページを離れるとき・画面が隠れたときに行う。保存できない端末でも遊べる。

## 5. 主な仕組み

### 5.1 メダルの流れ
1. 投入：狙い（-1〜1）の位置に落とす。チャッカーの真上で扉が開いていれば、入ってスロットの保留が 1 つ増える。
2. 上段のプッシャーが下段へ、下段のプッシャーが手前へ押し出す。手前から落ちたメダルは持ちメダルへ。横のすき間に落ちたメダルは戻らない（ジャックポットの額へ少し入る）。
3. スロットが当たるとボールが上段に落ちてくる。ボールが手前（または横）から落ちるとルーレットへ。
4. 払い出しが多いときは、60 枚（ジャックポットは 120 枚）までを台の上に流し込み、残りは直接持ちメダルへ。

### 5.2 ジャックポットの額
- 投入 1 枚ごとに 0.06、チャッカーに入ると 0.3、横に落ちると 0.2 ずつ額が増える（端数は持ち越す）。
- ジャックポットのあとは 500 に戻り、帆ゲージも 0 に戻る。

### 5.3 毎コマの進行
- 台のルールは 1/60 秒ずつ進める（画面の速さに関係なく同じ動き）。1 コマで進めるのは 10 歩まで。
- 押し続け・自動のときは、決まった間隔でメダルを入れる。
- 出来事（`GameEvent`）を画面が受け取り、音・振動・表示に変える。ルールの側は画面を知らない。

### 5.4 毎日のメダル
- 50・80・100・150・200・250・500 枚（7 日で一回り）。前の日に受け取っていれば次の日数、空いたら 1 日目から。

## 6. 表示

- three.js の 3D。WebGL が使えなくても、ルールと操作の画面は動く。
- 演出の強さは 3 段。動きを減らす設定の端末では「控えめ」がはじめの設定。
- 台をなぞるか下のつまみで狙う。投入・押し続け・自動のボタン。

## 7. テスト

| テスト | 中身 |
|---|---|
| `tests/game.test.ts` | メダルの動き（手前から落ちたら払い出し・壁の外に出ない）・台のルール（数が合う・長く遊ぶと戻りはおよそ 7〜11 割・メダルがなければ入れられない・チャッカーからルーレットまでの流れ・ジャックポット・保存と読み込み）・毎日のメダル |
| `tests/e2e.mjs`（`npm run e2e`） | 画面テスト（PC・スマホ）：今日のメダル・3D とはみ出し・投入と自動・ルーレット・ジャックポット・記録と設定・読み込み直してもメダルが残る |

- 画面テストは `?fast` で 8 倍速にして動かす。

## 8. 決まりごと

- 台の名前・絵・演出は独自のもの。
- メダルはゲームの中だけ。課金・換金・景品の仕組みを足さない。
- 戻り（入れた数に対してもらえる数）は、テストでおよそ 7〜11 割に収める。ルールの値を変えたら、このテストで確かめる。
- 保存の形を変えたときは、`SaveData` の `v` とキーの版を上げる。
