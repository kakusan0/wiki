# 星海の宝船 — メダルプッシャー

ブラウザで遊べる 3D のメダルプッシャーです。スマホにも対応しています。

## 遊び方
- 台をなぞるか下のつまみで狙う位置を決めて、「投入」でメダルを落とします（押し続け・連続投入・自動もあり）。
- 上段・下段のプッシャーがメダルを押し出し、手前から落ちたメダルがもらえます。横のすき間に落ちたメダルは戻りません。
- 奥の 3 つのチャッカーに入ると液晶のスロットが回り、そろうとボールが出ます。ボールが手前から落ちると星図ルーレットへ。
  - 波 +10 枚・星 +30 枚・帆（ゲージ +1、+5 枚）・宝（ジャックポットのチャンス）
  - 帆が 7 つたまると満帆でジャックポット。
- 毎日 1 回、メダルの配給があります（7 日で一回り、続けて来るほど多い）。
- メダルはゲームの中だけのものです。買うこと、お金や景品に換えることはできません。

台の名前・絵・演出は、このゲームのために作った独自のものです。

## 設計
作りの全体（ファイルの役割・データ・仕組み・サーバー・テスト）は [設計書](docs/design.md) にあります。

## 開発
```bash
npm ci
npm run dev
npm test      # 物理・台のルール・毎日のメダルの単体テスト
npm run e2e   # 画面テスト（PC・スマホ）
```

## 公開
Cloudflare Workers（静的ファイルのみ）。main に push すると Workers Builds で自動で公開されます。
